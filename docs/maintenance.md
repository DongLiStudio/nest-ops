# 升级、备份、恢复与卸载

升级前保留 compose、镜像摘要、自定义配置、认证数据、TLS、令牌和 SQLite 一致性备份。不要把实时 SQLite 主文件单独复制作为有效备份；停止 console 后连同数据目录复制，或使用 sqlite3 backup API。

先在独立目录和独立端口验证新版本，再替换正式实例。运行 docker compose pull、config --quiet、up -d 后检查所有服务、认证和数据。内附 Homepage 源码不代表镜像或依赖可离线取得；提前缓存并校验镜像。回退时恢复旧版本 Compose/扩展/镜像，保留数据库；有数据库迁移时按该版本说明回退。

恢复：安装 Docker、准备原有私有配置和证书、恢复一致性数据库、核对目录权限、docker compose up -d；确认采集端令牌与中心一致。不要在恢复时自动生成新密钥覆盖原身份。

卸载中心：docker compose --profile oidc down。默认保留 runtime 全部配置和历史；确认不再需要后由管理员定向删除。先卸载远端采集器并撤销令牌。证书续期、DNS及其他共享服务不由此卸载。

此项目不提供业务数据库备份或所有服务器的统一备份方案；这些可以接入独立备份系统。
